# Packages Docs

A list of all packages available inside Flow Client Library (FCL) with functions and type definitions.

* [@onflow/fcl](/build/tools/clients/fcl-js/packages-docs/fcl) - High-level JavaScript/TypeScript library for building web applications on the Flow blockchain.
* [@onflow/sdk](/build/tools/clients/fcl-js/packages-docs/sdk) - Low-level JavaScript/TypeScript SDK for interacting with the Flow blockchain.
* [Type Definitions](/build/tools/clients/fcl-js/packages-docs/types) - Type definitions for the Flow Client Library (FCL) packages.
